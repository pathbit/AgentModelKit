# Changelog

[Português (Brasil)](CHANGELOG.md) · [Español](CHANGELOG.es.md)

## 0.0.3

- Package commands in Portuguese, English, and Spanish include `@latest` and the pinned version `@0.0.3`.
- GitHub Releases use the `agentmodelkit-<version>.tgz` filename format.
- CI checks that installation examples match the package version.

## 0.0.2

- `--version` and `-v` print the version declared in the package.
- Reapplying VS Code setup preserves custom headers and secret references for the same endpoint.
- The release checks that npmjs serves the public tarball and that it matches the CI artifact.
- Product requirements, the terminal experience, and the roadmap record delivery scope and checks.

## 0.0.1

- Runtime dependency-free CLI that configures VS Code and GitHub Copilot CLI through `npx`.
- OpenCode Go/PAYG, FreeLLMAPI and local provider manifests.
- Incremental additions, optional replacement, backups and removal of models confirmed missing upstream.
- Bundled catalogs, refreshable cache, versioned editorial selection and monthly source checks.
- Chat Completions, Responses and Messages protocol support.
- Validation and publishing workflow for npmjs and GitHub with maintainer approval.
- Brazilian Portuguese, English and Spanish documentation with an English CLI.
- Native per-project OpenCode 2 configuration and checkbox selection for coding agents.
