## Unreleased

- `--version` and `-v` print the package version.
- Reapplying VS Code setup preserves custom headers for the same endpoint and replaces the authentication header when a new key is provided.

## 0.0.1

- Runtime dependency-free CLI that configures VS Code and GitHub Copilot CLI through `npx`.
- OpenCode Go/PAYG, FreeLLMAPI and local provider manifests.
- Incremental additions, optional replacement, backups and removal of models confirmed missing upstream.
- Bundled catalogs, refreshable cache, versioned editorial selection and monthly source checks.
- Chat Completions, Responses and Messages protocol support.
- Validation and publishing workflow for npmjs and GitHub with maintainer approval.
- Brazilian Portuguese, English and Spanish documentation with an English CLI.
- Native per-project OpenCode 2 configuration and checkbox selection for coding agents.
