# Roadmap

[English](ROADMAP.en.md) · [Español](ROADMAP.es.md)

## Publicado

- [x] [0.0.1](releases/v0-0-1/RELEASE.md) no npmjs, GitHub Packages e GitHub Release.

### Recursos entregues

- Configuração do OpenCode, do VS Code e do Copilot CLI com seleção interativa ou parâmetros.
- Adição incremental, substituição explícita, remoção por disponibilidade e backups.
- Catálogo incluído no pacote, atualização manual e rotina mensal de revisão.
- Providers OpenCode, FreeLLMAPI e endpoints definidos por manifesto.
- Teste de pacote e fluxo de publicação por tag com aprovação do mantenedor.

## Evolução

- Revisão mensal da curadoria com o motor de IA da PathBit, incluindo critérios e aprovação das mudanças. Enquanto isso, a curadoria versionada é revisada manualmente com o patch mensal das origens.
- Integrações adicionais de clientes e descoberta de novos providers a partir de catálogos oficiais.
