# Changelog

[English](CHANGELOG.en.md) · [Español](CHANGELOG.es.md)

## 0.0.2

- `--version` e `-v` exibem a versão declarada no pacote.
- Reaplicar a configuração do VS Code preserva os cabeçalhos personalizados e as referências a segredos no mesmo endpoint.
- A release verifica se o tarball público do npmjs está disponível e se corresponde ao artefato da CI.
- Requisitos, experiência no terminal e roadmap passam a registrar o escopo e as verificações da entrega.

## 0.0.1

- CLI sem dependências de runtime para configurar VS Code e GitHub Copilot CLI com `npx`.
- OpenCode Go/PAYG, FreeLLMAPI e providers definidos por manifesto local.
- Adição incremental, substituição opcional, backups e remoção de modelos ausentes confirmados pela origem.
- Catálogos distribuídos no pacote, cache atualizável, curadoria versionada e verificação mensal das fontes.
- Suporte aos protocolos Chat Completions, Responses e Messages.
- Fluxo de validação e publicação no npmjs e GitHub após aprovação.
- Documentação em português do Brasil, inglês e espanhol com a CLI em inglês.
- Configuração nativa de OpenCode 2 por projeto e seleção de agentes com checkboxes.
