## En desarrollo

- `--version` y `-v` muestran la versión del paquete.
- Al volver a aplicar la configuración de VS Code, se conservan las cabeceras personalizadas para el mismo endpoint y se actualiza la autenticación cuando se proporciona una clave nueva.

## 0.0.1

- CLI sin dependencias de ejecución para configurar VS Code y GitHub Copilot CLI mediante `npx`.
- OpenCode Go/PAYG, FreeLLMAPI y proveedores definidos por manifiestos locales.
- Adiciones incrementales, sustitución opcional, copias de seguridad y eliminación de modelos cuya ausencia se confirma en el origen.
- Catálogos incluidos en el paquete, caché actualizable, selección editorial versionada y verificación mensual de las fuentes.
- Compatibilidad con los protocolos Chat Completions, Responses y Messages.
- Flujo de validación y publicación en npmjs y GitHub con aprobación del mantenedor.
- Documentación en portugués de Brasil, inglés y español con la CLI en inglés.
- Configuración nativa de OpenCode 2 por proyecto y selección de agentes con casillas.
